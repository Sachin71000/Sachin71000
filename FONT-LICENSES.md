# Embedded font licenses

The SVG assets embed font files directly as base64 data so GitHub makes no font requests.

- **Ubuntu Bold** — Copyright Canonical Ltd.; licensed under the Ubuntu Font Licence 1.0. Source: <https://design.ubuntu.com/font>
- **Source Code Pro Regular** — Copyright Adobe; licensed under the SIL Open Font License 1.1. Source: <https://github.com/adobe-fonts/source-code-pro>

The embedded fonts are used only to render text inside this profile’s SVG assets.
